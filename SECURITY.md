# Security Policy

## Supported Versions

Only the [latest release](https://github.com/artginzburg/WheelClick-Community/releases/latest) is supported. WheelClick updates itself, so staying current is the default.

## Reporting a Vulnerability

Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/artginzburg/WheelClick-Community/security/advisories/new) — do **not** open a public issue.

You can expect an initial response within 72 hours. Please leave time for a fix to ship before any public disclosure.

Urgent? Email [support@wheelclick.app](mailto:support@wheelclick.app) — it's checked much more often.

## Scope

- The WheelClick app and its update mechanism
- The [wheelclick.app](https://wheelclick.app) website and its API

WheelClick runs sandboxed, talks to no servers except for updates, licensing, and anonymous telemetry, and its releases are signed and notarized. If you see behavior that contradicts this, that alone is worth a report.
